## Pre-requisites
- Node.js v24.x
- [pnpm](https://pnpm.io/installation) package manager

## Installation

1. Clone reprository

```bash
git clone
cd autocomplete-ui
```

2. Install dependencies

```bash
pnpm install
```

## Run the application locally

1. Start development server

```bash
pnpm dev
```

2. Visit application at `http://localhost:5371`
